# Report Builder Documentation

Laravel Report Builder is a package for defining **safe, source-driven reports** in code and running them for preview/export, with optional saved definitions and schedule metadata.

## Who this package is for

Use this package if you are:

- a Laravel developer who wants to expose reporting without unrestricted query builders,
- defining reportable domains as explicit report sources and fields,
- building internal tooling where previews/exports and saved report definitions are needed.

This package is **not** a no-code UI by itself; it provides the engine and APIs.
